# Spec 001: Greeting

- **Status:** Draft

## Problem / why
Callers need a polite greeting for a name.

## Requirements
- REQ-001-01: `greet(name)` returns `Hello, <name>!`.
- REQ-001-02: An empty or whitespace-only name raises `ValueError`.

## Acceptance criteria
- [ ] AC-01: both behaviours are covered by tests.
